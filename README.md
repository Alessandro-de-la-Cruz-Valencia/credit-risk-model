# Credit Risk Model: Probability of Default

Work in progress. Full documentation is added as the project progresses.

## Data

The project uses the [Give Me Some Credit](https://www.kaggle.com/c/GiveMeSomeCredit/data) dataset
from Kaggle. The data is **not** included in this repository because of Kaggle's competition rules.

1. Sign in to Kaggle, open the competition's **Data** tab and accept the rules.
2. Download `cs-training.csv` (or run `kaggle competitions download -c GiveMeSomeCredit`).
3. Place it at `data/raw/cs-training.csv`.
